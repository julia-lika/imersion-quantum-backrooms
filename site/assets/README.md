# Assets

## Yasu's Backrooms Material Pack

The wall, floor and ceiling textures are from Yasu's pack and are licensed
under CC BY 4.0. The original license and README are kept in `textures/yasu/`.

The Level 0 set used by the game lives in `textures/level0/`. These files were
resized from the 4K originals so they load fast and fit in the Quest's memory:

| File | Source | Size |
| --- | --- | --- |
| `wallpaper-color.jpg` | `Backrooms_Wallpaper_01_Color` | 1024 |
| `carpet-color.jpg` | `Backrooms_Carpet_01_Color` | 1024 |
| `carpet-normal.jpg` | `Backrooms_Carpet_01_Normal` | 512 |
| `ceiling-tile-color.jpg` | `Backrooms_Ceiling_01_Color` | 512 |
| `light-panel.jpg` | `Backrooms_Ceiling_04_Color` + `Backrooms_Ceiling_04_Emissive` | 512 |

Attribution: Yasu / @mvyasu
Source: https://mvyasu.itch.io/backrooms-material-pack

## Game Ready Backrooms Asset Pack Vol. 2

`models/backrooms-vol2.glb` comes from Oxygen's pack. The itch.io page lists
the pack as CC0 1.0 Universal.
Its embedded texture atlas was re-encoded from a 2048 PNG to a 1024 JPEG to
cut the file from 5.8 MB to 1.3 MB.

Source: https://oxygen3d.itch.io/game-ready-backrooms-asset-pack-vol-2

## Ottoman Empire Signs

The sign texture is used as a temporary wall prop. The original Blender source
is preserved in `assets-source/ottoman/` because the downloaded package does
not include a machine-readable license file. Confirm the creator's usage terms
before publishing or distributing the project.

Source: https://bluebarrytv.itch.io/ottoman-empire-signs
